# Woordjes — картки для нідерландських слів

Особистий статичний вебзастосунок для запам'ятовування нідерландських слів через картки.
Українське слово на лицьовому боці, нідерландський переклад — на звороті, з озвученням.

Працює повністю в браузері: без backend, бази даних, npm і процесу збирання.

## Можливості

- Словники: створення, редагування, видалення (з підтвердженням).
- Редактор: усі слова одразу показані в полях. Можна додавати й видаляти рядки, `Enter` переходить до наступного поля, `Ctrl/⌘ + S` зберігає. Вставлений список рядків `слово: woord` розбивається на окремі рядки.
- Імпорт CSV (кнопкою або перетягуванням файлу на сторінку).
- Навчання: картки перемішуються; «Знаю» прибирає слово із сесії, «Не знаю» переносить його до наступного раунду (теж перемішаного). Сесія триває, доки не вивчено всі слова.
- Прогрес `68 / 100` з progress bar, таймер, екран завершення з часом і кількістю раундів.
- Мобільні жести: свайп вправо — «Знаю», вліво — «Не знаю», дотик — перевернути картку.
- Клавіатура: `Space` / `↑` / `↓` — перевернути, `→` — «Знаю», `←` — «Не знаю», `S` — вимова, `Enter` — наступний раунд.
- Світла й темна тема (за системними налаштуваннями), адаптивний дизайн від 320 px до великих моніторів.

## Запуск локально

JavaScript підключено як ES-модулі, тому сторінки треба відкривати через локальний HTTP-сервер,
а не через `file://`. Підійде будь-який статичний сервер, наприклад:

```bash
python3 -m http.server 8000
```

Потім відкрийте <http://localhost:8000>.

Інший варіант — розширення Live Server у VS Code.

## GitHub Pages

1. Завантажте всі файли в корінь репозиторію.
2. Відкрийте **Settings → Pages**.
3. У **Build and deployment** оберіть **Source: Deploy from a branch**, гілку (наприклад, `main`) і папку `/ (root)`.
4. Натисніть **Save**. За хвилину-дві сайт з'явиться за адресою `https://<username>.github.io/<repository>/`.

Усі шляхи відносні, тому сайт працює і в підпапці репозиторію.

## Формат CSV

Кожен рядок містить одну пару: українське слово і нідерландський переклад.

```
будинок: huis
вода: water
машина: auto
собака: hond
```

- Розділювач: `:` (основний), `;`, `,` або табуляція. Він визначається автоматично.
- Поля можна брати в лапки: `"сир, твердий";kaas`.
- Порожні рядки та рядки, що починаються з `#`, ігноруються.
- Некоректні рядки (без перекладу) пропускаються, і застосунок показує, скільки їх було.
- Зайві пробіли прибираються, однакові пари об'єднуються.
- Рядок-заголовок на кшталт `українське;нідерландське` пропускається.
- Кодування: UTF-8 (з BOM або без нього). Якщо файл не є коректним UTF-8, його буде прочитано як Windows-1251.
- Обмеження: файл до 2 МБ, до 5000 слів, слово до 120 символів.

Після вибору файлу застосунок показує, скільки слів знайдено, і просить ввести назву словника.

## LocalStorage

Усі словники зберігаються в одному ключі `woordjes:dictionaries:v1` як JSON-масив:

```json
[
  {
    "id": "3f0c…",
    "name": "Dutch A1",
    "words": [
      { "uk": "будинок", "nl": "huis" },
      { "uk": "вода", "nl": "water" }
    ]
  }
]
```

Більше нічого в LocalStorage не записується. Прогрес навчання, таймер і раунди існують тільки
в пам'яті JavaScript, тож після перезавантаження сторінки сесія починається заново.

Дані прив'язані до браузера й домену. Якщо очистити дані сайту або відкрити його в іншому браузері, словників там не буде.

## Озвучування (Web Speech API)

Для вимови використовується вбудований у браузер `SpeechSynthesis` / `SpeechSynthesisUtterance`
з мовою `nl-NL`. Сторонні сервіси не використовуються.

Якість і наявність нідерландського голосу залежать від браузера та операційної системи.
Якщо голосу `nl-NL` немає, браузер використає голос за замовчуванням. На iOS і macOS його можна завантажити в
системних налаштуваннях: **Універсальний доступ → Усний вміст → Голоси**. Якщо браузер не підтримує
Web Speech API, кнопку озвучування буде приховано.

## Безпека

- Текст користувача вставляється тільки через `textContent` / текстові вузли, без `innerHTML` і `eval()`.
- Дані з LocalStorage під час читання перевіряються й очищуються (Unicode NFC, керівні символи, довжина).
- Пошкоджений JSON у сховищі не ламає застосунок.
